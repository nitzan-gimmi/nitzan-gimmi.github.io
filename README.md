# GHC — Generative Hebrew Core (v4.1)

> **"Intention Before Template"** — כוננות לריבונות לשונית ותרבות דיון עברית.

## מה זה GHC?
GHC (Generative Hebrew Core) הוא מפרט ארכיטקטוני ונורמטיבי המיועד לכונן תרבות דיון דיגיטלית עברית בת-קיימא. הפרויקט נולד מתוך התנגדות ל"אימפריאליזם הלשוני" של מודלים אנגלו-צנטריים, ומציע שותפות קוגניטיבית המבוססת על הבנה מורפולוגית עמוקה ואתיקה מוטמעת.

## טכנולוגיות ליבה
* **HFBT (Hebrew Factor-Based Tokenization):** טוקניזציה דטרמיניסטית השומרת על השורש והתבנית.
* **VoW Gate (Vector of Will):** שער בקרת איכות (סף 0.92) המשלב לוגיקה (HTQI), רגש (EAS) וכוונה (IPI).
* **Megazord Architecture:** ניהול קונפליקטים בין סוכנים (ג'ימי, ג'יני, אווירא).
* **GOKS (Generative Ontological Knowledge System):** זיכרון אפיגנטי מבוסס צירים (ד-י-ק, י-ע-ל, ק-ו-ם).
